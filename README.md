# ДонРецепты.ру

## Настройка проекта для тестовой среды

### Запуск backend-сервиса в docker-compose
Можно найти инструкцию в репозитории [don-receipt-backend](https://github.com/donntu-legacy-team/don-receipt-backend)

### Определение переменных окружения в .env
Если вы запустили backend-сервис в docker-compose, не изменяя переменных окружения, то достаточно скопировать файл `.env.example` и переименовать в `.env`.

Иначе определите свои значения переменных.

### Установка зависимостей

```bash
$ npm install
```

### Запуск проекта

```bash
$ npm run dev
```
